
# Atividade – Elicitação de Requisitos

## Processo 1 – Registro de pedidos pelos vendedores

**Requisito 1.** O sistema deve permitir que o vendedor registre pedidos informando o cliente, os produtos e as quantidades.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Formulário ou modelo de pedido utilizado atualmente pela empresa. Fonte não humana, categoria documentação.

**Requisito 2.** O sistema deve registrar a forma de pagamento escolhida no momento da venda.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Política comercial sobre formas de pagamento aceitas. Fonte não humana, categoria documentação.

**Requisito 3.** O sistema deve permitir que o vendedor consulte o status dos pedidos registrados.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Entrevista com o administrador responsável pelo acompanhamento das vendas. Fonte humana, nível tático, classe de usuário administrador.

---

## Processo 2 – Cadastro e remoção de produtos

**Requisito 1.** O sistema deve permitir que o administrador cadastre produtos informando nome, preço e descrição.

Fonte 1. Entrevista com o administrador. Fonte humana, nível tático, classe de usuário administrador.

Fonte 2. Catálogo de produtos utilizado pela empresa. Fonte não humana, categoria documentação.

**Requisito 2.** O sistema deve permitir que o administrador remova produtos do catálogo.

Fonte 1. Entrevista com o administrador. Fonte humana, nível tático, classe de usuário administrador.

Fonte 2. Política interna sobre cadastro e remoção de produtos. Fonte não humana, categoria documentação.

**Requisito 3.** O sistema deve permitir que o administrador altere as informações e os preços dos produtos cadastrados.

Fonte 1. Entrevista com o administrador. Fonte humana, nível tático, classe de usuário administrador.

Fonte 2. Análise de sistemas concorrentes de vendas e cadastro de produtos. Fonte não humana, categoria concorrência.

---

## Processo 3 – Controle de estoque

**Requisito 1.** O sistema deve permitir que o time de estoque registre a entrada de produtos, informando a quantidade recebida.

Fonte 1. Entrevista com o funcionário responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoquista.

Fonte 2. Notas fiscais e documentos de recebimento de mercadorias. Fonte não humana, categoria documentação.

**Requisito 2.** O sistema deve dar baixa automaticamente na quantidade disponível de um produto após a confirmação de um pedido.

Fonte 1. Entrevista com o funcionário responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoquista.

Fonte 2. Fluxo de registro de pedidos utilizado pelos vendedores. Fonte humana, nível operacional, classe de usuário vendedor.

**Requisito 3.** O sistema deve permitir que o time de estoque consulte a quantidade disponível de cada produto.

Fonte 1. Entrevista com o funcionário responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoquista.

Fonte 2. Planilhas de controle de estoque utilizadas atualmente pela empresa. Fonte não humana, categoria documentação.
